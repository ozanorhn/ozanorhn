I’m Ozan, an AI Automation Engineer based in Hannover, Germany. I design and build systems where language models work with real tools, data and workflows — not just chat interfaces.

My focus: agent orchestration, MCP integrations, retrieval-augmented generation, reliable automations and self-hosted infrastructure. I care about the engineering around the model: permissions, validation, observability, fallbacks and human approval.

> **Build the workflow. Connect the tools. Keep humans in control.**

🔄 How I think about agent systems

flowchart LR
    U["User / Event"] --> A["Agent / n8n"]
    A --> T["MCP Tools / APIs"]
    T --> D[("Data & Services")]
    A --> V["Validate Output"]
    V --> G{"Sensitive action?"}
    G -->|Yes| H["Human Approval"]
    G -->|No| X["Execute / Respond"]
    H --> X
    X --> O["Logs & Feedback"]

A useful AI system isn’t just a model call. It’s a reproducible process with well-defined tools, clear boundaries, validation and a way to recover when things fail.
